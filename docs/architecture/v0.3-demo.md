# AMRGuard v0.3.0 — Pitch Demo

This release adds a responsive web interface over the AMRGuard API.

## Demo workflow
1. Overview → Prescriptions
2. Load e-Buzima demo prescription
3. Pharmacy Verification → use QR or OTP `482913`
4. Continue to Dispensing
5. Select pharmacy/batch and quantity 15
6. Authorize & record dispensing
7. Review Batch Traceability
8. Review Analytics / Integrations

## Production boundary
The demo uses seeded data and an e-Buzima simulator. No live government endpoint or production credential is claimed. External systems are connected through adapters and stable AMRGuard internal contracts.
